# 新方案设计提案

## 核心变化

**从「用户选择 → AI计算」变为「AI推荐 → 用户挑选」**

### 参与者与时区

| 参与者 | 位置 | 时区 | 角色 |
|--------|------|------|------|
| 你 (Jack) | 中国 | UTC+8 (北京时间) | 主操盘，与 Claude 交互 |
| Brian | 加拿大 | UTC-4/-5 (东部时间) | 合伙人，参与决策 |
| Claude | - | - | AI 概率分析，生成推荐 |

### 比赛时间分布（北京时间）

2026 世界杯在北美举办，比赛时间转换为北京时间：
- 早场：北京时间 02:00-05:00（美东 14:00-17:00）
- 晚场：北京时间 05:00-08:00（美东 17:00-20:00）
- 深夜场：北京时间 08:00-11:00（美东 20:00-23:00）

**关键事实：绝大多数比赛在北京时间凌晨-上午进行，竞彩投注截止时间为比赛开赛前。**

### AI 推荐页 — 体现概率优势

每个推荐方案卡片：

```
│                                             │

│                                             │
│ ③ 荷兰 vs 塞内加尔  →  荷兰胜  @2.20         │
│   庄家隐含 45% → AI修正 51%  价值 +6%↑        │
├─────────────────────────────────────────────┤
│ 📊 AI 分析摘要                                │
│ ┌─────────────────────────────────────────┐ │
│ │ 三串一命中概率                            │ │
│ │ 庄家隐含: 19% ━━━━━░░░░░░░░░░           │ │
│ │ AI 修正:  26% ━━━━━━━░░░░░░░░           │ │
│ │                                         │ │
│ │ 期望价值(EV): +0.85 ✓ 正EV=值得投        │ │
│ │ Kelly建议: 全额 (置信度高)               │ │
│ └─────────────────────────────────────────┘ │
├─────────────────────────────────────────────┤
│         [ 选择此方案 ]                        │
└─────────────────────────────────────────────┘
```

**AI 概率优势体现在：**

1. **隐含概率 vs AI修正概率** — 赔率背后的真实概率，去除庄家抽水后的修正值
2. **价值指数** — AI修正概率 - 隐含概率，正值=发现了市场低估的机会
3. **三串一整体命中概率** — 独立事件概率乘积，直观展示 AI 认为的真实中奖率
4. **期望价值(EV)** — 赔率 × AI命中概率 - 1，正数才推荐，负数绝不推
5. **Kelly 公式** — 科学判断是否值得满额投注
6. **推荐理由（可展开）** — 每条 leg 的选择依据：战绩、排名、状态、交锋记录等

### 三档分类

| 档位 | 赔率区间 | 色彩 | 典型组合 | 命中率预期 |
|------|---------|------|----------|-----------|
| 🟢 保守型 | 5-10倍 | 绿色 | 两场强队让球胜 + 一场中赔 | 10-15% |
| 🟡 进取型 | 10-20倍 | 橙黄 | 混合胜平负+让球，平衡配置 | 5-10% |
| 🔴 激进型 | 20倍+ | 红色 | 包含冷门/高赔平局 | 2-5% |

## 前端技术实现要点

1. **推荐页动态加载** — 从 GitHub API 读取 `recommendations/{date}.json`，按三档渲染卡片
2. **确认提交** — 用户点选一档后弹出口令输入框 → POST 到 Pages Function → 写入 GitHub
3. **赛程页** — 读取 `data/matches/{date}.json`，渲染比赛卡片，已结束的显示比分
4. **策略建议** — 读取 `data/ledger.json` 最近3条记录，判断连续未中天数，顶部提示
5. **概率可视化** — 横向进度条对比庄家隐含概率 vs AI修正概率，直观展示价值
